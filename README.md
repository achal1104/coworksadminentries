# Visitor QR Scanner → Excel

Separate project. Scans the QR generated by the visitor-management app and appends each entry to `data/visitors.xlsx`.

## Run
```
npm install
npm start            # http://localhost:3000
npm run start:https  # for phone camera over Wi-Fi (accept the browser's self-signed warning)
```
Open the URL, press **Start camera**, scan. The Excel file is `data/visitors.xlsx` (also the "⬇ Excel" button).
Duplicate scans of the same Registration ID are rejected. Close the file in Excel before scanning (Windows locks it).
